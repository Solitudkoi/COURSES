# 缓存仿真说明

## 改进项

### 1. 打印时序修复

- **问题**：之前在 `posedge clk` 时直接打印当前信号，会混淆命令和响应
- **解决**：使用寄存器延迟一个周期，打印上一周期命令的缓存响应

### 2. u_b_h_w设置修复

- **问题**：初始store操作时没有设置 `u_b_h_w`
- **解决**：在所有store/load/edit操作中明确设置 `u_b_h_w <= 3'b010`

### 3. Hit/Miss 状态详细说明

- 打印格式改为：命令类型 + 具体结果
- LOAD/STORE/EDIT后会明确显示 HIT 或 MISS
